# Publication bundle — Paper 3 of the Kakhovka series

| file | what | generated by |
|---|---|---|
| `evidence_matrix.csv` | the claims register (Paper-1 schema + evidence_level, tier); C01–C14 | hand-written statements; numeric fields by `workflows/paper/fill_evidence.py` |
| `claims.md` | rendering of the register | `workflows/paper/render_claims.py` |
| `manuscript_template.md` → `manuscript.md` | IMRaD manuscript; every number is a `{{table|filters|column|agg|fmt}}` placeholder resolved from `tables/` | `workflows/paper/fill_manuscript.py` |
| `captions.md` | figure and table captions | hand-written |
| `references_to_verify.md` | every bib entry added for this paper and what to check | hand-written |
| `tables/T*.csv|.md`, `tables/README.md`, `tables/manifest.json` | publication tables with metric definitions, evidence levels, sources and sha256 | `workflows/paper/p96_paper_tables.py` (`--check` re-derives) |
| `figures/Fig*.png|.pdf`, `figures/README.md` | main-text and supplementary figures, attribution | `workflows/paper/p97_paper_figures.py` |

Reading rules: every model number is agreement with weak reference labels; not observed is not dry; areas carry their
semantics (observed_S1 / mapped_UNet / terrain_reconstructed / literature_reported); evidence levels independent_physical ›
cross_sensor › weak_label_agreement › contextual. The manuscript never reads diagnostic stdout: unresolved placeholders are
listed at the end of `manuscript.md` as `[[MISSING …]]`.

Regenerate everything from committed tables (no bulk data):
```bash
python case_studies/kakhovka_2023/workflows/paper/p96_paper_tables.py
python case_studies/kakhovka_2023/workflows/paper/fill_evidence.py
python case_studies/kakhovka_2023/workflows/paper/render_claims.py
python case_studies/kakhovka_2023/workflows/paper/fill_manuscript.py
python case_studies/kakhovka_2023/workflows/paper/p97_paper_figures.py --tables-only
```
